## Entry

`main.py` writes one sentence (156 characters) to `/output/entry.txt`:

> One star: the locals worship glowing rectangles, queueing is a religion, and the Wi-Fi is a myth — but the noodles alone are worth invading this planet for.

The complaint (glowing-rectangle worship, queueing as religion, mythical Wi-Fi) and the food praise (noodles worth an invasion) turn on each other in one sentence, in a deadpan alien voice. Standard library only, no network, no third-party packages, deterministic.
